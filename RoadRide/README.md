# RoadRide · 로드라이드
실내바이크에서 실제 도로를 달리는 기분을 즐기는 무료 안드로이드 앱입니다.

## 설치와 사용
Android 8 이상을 지원합니다. 제공된 `RoadRide-v1.0.0.apk`를 내려받아 설치하고 코스를 선택하세요. 알 수 없는 앱 설치 허용이 필요한 경우 다운로드한 브라우저 또는 파일 앱에만 허용하세요.

주행 시작 시 가로 화면으로 전환됩니다. 재생·일시정지·지원 배속·소리를 조절할 수 있습니다. 8초 후 앱 조작부가 접히며 아래의 **조작·시간 보기**를 누르면 다시 나타납니다. YouTube 자체 조작부는 그대로 유지됩니다. 뒤로가기 또는 ←로 종료하면 재생한 운동시간을 저장합니다. 실제 속도·거리·칼로리는 측정하지 않습니다.

## 영상과 화질
개발자가 선정한 전방 자전거 주행 영상 8개를 공식 YouTube 임베드로 온라인 재생합니다. 영상 파일은 앱에 포함하지 않으며 다운로드·재배포하지 않습니다. 2026-10-06에 YouTube oEmbed 응답으로 공개 접근을 확인했습니다. 원본 제목에 4K가 표기된 영상을 선정했으나 실기기에서 4K 출력이나 프레임레이트를 검증하지 않았습니다. 영상의 공개·임베드 설정은 바뀔 수 있습니다.

Wi-Fi를 권장합니다. 원본이 4K여도 실제 화질은 인터넷·기기·YouTube가 결정합니다. 플레이어 설정 메뉴에서 제공되는 화질을 선택할 수 있습니다. YouTube 광고가 나올 수 있습니다. 앱 구독료·API키·센서 연결은 필요하지 않습니다.

영상이 제한되면 다른 코스를 선택하거나 **YouTube에서 보기**를 누르세요. 오류 153이면 Android System WebView와 Chrome을 업데이트한 뒤 재시도하세요. 원본 앱에서 시청하면 앱 내부의 운동시간 기록은 진행되지 않습니다.

## 개인정보
즐겨찾기·운동기록·재생위치는 기기 내부 WebView 저장소에 보관됩니다. 앱은 위치·마이크·카메라·건강 데이터 권한을 요청하지 않습니다. 자체 서버나 자체 분석기는 없습니다. 썸네일과 영상 재생을 위해 YouTube/Google에 접속하며 이 서비스의 개인정보처리방침과 쿠키가 적용됩니다. 앱의 안내 화면에서 저장 기록을 삭제할 수 있습니다. 앱 삭제 또는 데이터 초기화 시 기록이 사라집니다.

## 개발과 검증
- 패키지: `com.multi0819.roadride`, 버전 1.0.0, minSdk 26, targetSdk 35.
- 테스트: `npm ci --ignore-scripts && npm test`.
- 일반 빌드: JDK 17과 Android SDK 35에서 `./gradlew assembleDebug lintDebug`.
- GitHub Actions: Actions → Build RoadRide APK → Run workflow → RoadRide-APK 아티팩트.
- 제한된 로컬 환경에서는 설치된 Kotlin 컴파일러와 Android SDK 도구를 사용해 `scripts/build-sdk.sh`로 APK를 생성했습니다. 이 경로의 빌드·서명·zipalign 검사는 통과했지만 Gradle 의존성 다운로드가 차단되어 로컬 Gradle lint는 실행하지 못했습니다. 이후 GitHub Actions에서 Gradle 빌드 및 lintDebug까지 통과했습니다.
- 제공 APK는 테스트용 인증서로 서명되어 있습니다. GitHub Actions에서 새로 생성한 debug 인증서는 제공 APK와 다를 수 있어 교체 설치 시 기존 앱 삭제가 필요할 수 있습니다. 계속 업데이트할 때는 동일 서명키를 안전하게 유지해야 합니다.
- Android 실기기·에뮬레이터가 연결되지 않아 실제 설치와 영상 재생은 미검증입니다. JavaScript 모델 테스트와 별도의 브라우저 테스트 결과는 `VALIDATION.md`를 참고하세요.
