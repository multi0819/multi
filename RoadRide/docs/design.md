# RoadRide — 실내바이크 도로 주행 앱 설계

## 목표
안드로이드 실내바이크 사용자가 센서나 앱 구독 없이 실제 도로를 달리는 분위기를 즐긴다. 사용자가 영상을 준비하지 않아도 개발자가 선정한 공개 영상으로 운동을 시작할 수 있다.

## 사용 흐름과 화면
한국어 인터페이스와 어두운 배경, 큰 코스 사진, 절제된 색상으로 구성한다. 홈에서 바다·산길·해외 코스를 선택하고 시작한다. 주행은 가로 전체화면으로 보여준다. 주행 영상과 조작 영역을 분리해 YouTube 플레이어 요소를 가리지 않는다. 앱 조작 영역은 일정 시간 후 숨기고 탭으로 다시 표시한다. 일시정지, 지원 배속 선택, 소리 켜기/끄기, 코스 종료를 제공한다. 화면 꺼짐을 방지한다.

## 영상과 화질
전방 1인칭 연속 주행, 자연스러운 속도, 적은 흔들림을 기준으로 공개 영상을 선정한다. 4K 및 가능하면 60fps 원본을 우선하지만 실제 출력 해상도는 YouTube·기기·네트워크가 결정한다. 화질을 강제로 보장하거나 광고를 제거하지 않는다. 영상은 공식 YouTube 임베드 플레이어로 온라인 재생하며 다운로드하거나 재배포하지 않는다. 코스 메타데이터에 제목, 분류, 원본 링크, 확인한 원본 해상도를 기록한다. 공개 여부와 임베드 가능 여부는 별도로 검증한다.

## 구현 구조
Android 앱 셸에서 WebView와 공식 IFrame Player API를 사용한다. 로컬 화면 자산은 Android HTTPS 자산 로더로 제공한다. 영상 공급자는 YouTube이고 별도 계정·결제 서버·지도 API는 없다. 외부 링크는 시스템 브라우저로 열며 WebView는 필요한 신뢰 도메인으로 제한한다. 앱 소스와 빌드 절차는 GitHub에 제공하고 설치 파일은 APK로 제공한다.

## 저장과 운동 기록
선택 코스와 마지막 재생 위치를 기기 내부에 저장한다. 실제 재생 중인 시간만 운동시간으로 합산하고 종료 시 날짜, 코스, 시간을 저장한다. 센서가 없으므로 실제 속도·거리·칼로리를 측정값처럼 표시하지 않는다. 재생 복원은 사용자가 이어보기를 누른 뒤 수행한다.

## 실패 처리
오프라인, 영상 삭제, 임베드 차단, 플레이어 오류를 한국어로 표시하고 재시도·다른 코스·원본 열기를 제공한다. 앱이 배경으로 이동하면 일시정지하고 자동 운동시간 누적을 중단한다. 재생 준비 이전에는 운동시간을 누적하지 않는다.

## 검증과 전달
APK 빌드, 코스 메타데이터 검증, 재생 상태에 따른 타이머와 기록 검증을 수행한다. 가능한 실행 환경에서 가로 화면, 재생·일시정지·배속·복원과 오류 처리를 확인한다. 실기기 검증이 불가능하면 해당 한계를 전달한다. GitHub 저장소 생성·업로드 가능 권한을 확인하고, 지원하지 않으면 필요한 저장소 정보를 요청한다. 기존 저장소를 임의로 덮어쓰지 않는다.

## 범위
센서 연결, 페달 자동 속도 동기화, 실제 지도 경로 탐색, 유료 영상 및 오프라인 YouTube 다운로드는 포함하지 않는다. 무료 앱 자체를 제공하되 인터넷 데이터 비용과 YouTube 광고는 별개다.
