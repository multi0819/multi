# RoadRide — S314 블루투스 케이던스 연결 설계

## 목적과 사용 순서
이미 설치한 Magene S314에서 페달 RPM을 받아 갤럭시탭의 로드라이드 영상 배속을 연동한다. 휴대폰과 Wi-Fi 중계는 필요하지 않으며, 영상 재생용 인터넷은 계속 필요하다.

1. 센서를 케이던스 모드로 설정하고 페달을 몇 바퀴 돌려 깨운다.
2. 탭에서 ‘블루투스 센서 연결’을 누른다. 필요한 Bluetooth 권한을 허용하고 검색된 S314를 선택한다.
3. 센서 RPM 수신을 확인하고 코스를 선택한 뒤 기존 ‘RPM 자동 연동’을 켠다.
4. 마지막 선택 센서를 기억해 다음에는 연결 버튼에서 재연결을 시도한다. 주소가 달라졌거나 검색되지 않으면 다시 검색·선택한다. 다른 앱이 센서를 사용 중이면 해당 연결을 종료하도록 안내한다.
5. 연결 해제는 앱의 연결 설정에서 명시적으로 할 수 있다.

## 연결 방식과 범위
- Android 네이티브 BLE GATT 클라이언트를 추가하고 표준 Cycling Speed and Cadence(CSC) 서비스 0x1816 / CSC Measurement 0x2A5B 알림을 구독한다. Android 설정의 일반 Bluetooth 페어링을 선행 조건으로 요구하지 않는다.
- S314가 표준 CSC 케이던스 값을 제공하는 것을 전제로 구현한다. 센서 이름만으로 호환을 확정하지 않으며 연결 후 서비스와 회전수 필드를 확인한다. 지원되지 않는 센서는 안내 후 종료한다.
- ‘휴대폰 연결’과 ‘블루투스 센서 연결’을 별도 버튼으로 제공한다. 하나의 입력원만 활성화하며 명시적으로 다른 입력원에 연결할 때 이전 소켓/GATT를 종료한다. 연결이 끊겨도 다른 측정기로 자동 전환하지 않는다.
- 기존 휴대폰 측정 기능, 영상·기록·몰입 화면·운동정보는 유지한다. 센서 수신 중 RPM 표시는 ‘센서 RPM’으로 구분한다. 시속·거리·칼로리는 계속 추정값이다.
- 센서 검색은 사용자가 시작할 때만 최대 15초 실행하며 종료/취소/앱 배경에서 검색을 중단한다. GATT 연결은 앱 화면과 주행 동안 유지하고 Activity 종료에서 닫는다. 백그라운드에서 영상 자동 재생이나 새로운 연결을 시작하지 않는다.

## RPM 처리
- CSC 플래그에 따라 바퀴 필드를 건너뛰고 크랭크 누적회전수와 마지막 회전 이벤트 시간을 읽는다. 크랭크 필드가 없으면 속도 모드일 수 있으므로 ‘케이던스 모드로 변경’ 안내를 제공한다.
- 누적회전수와 이벤트 시간은 16비트 순환값이다. 이벤트 시간 단위는 1/1024초이며 RPM = 회전수 변화 × 60 × 1024 ÷ 이벤트 시간 변화로 계산한다.
- 첫 샘플은 기준값만 설정한다. 정상 차분이 생긴 뒤에만 유효 RPM을 보낸다. 길이가 짧거나 손상된 알림, 이벤트 시간 0 변화, 비정상 차분/300RPM 초과, 장시간 공백 후의 첫 값은 유효 RPM으로 사용하지 않고 다시 기준을 잡는다.
- 같은 회전 이벤트가 3초 이상 유지되면 ‘페달 정지’로 처리한다. 알림/수신이 5초 이상 갱신되지 않으면 기존 오래된 값 보호를 적용한다. 원격 기기 시계를 탭의 현재 시각과 직접 비교하지 않는다.
- 연결마다 순번과 기준값을 초기화한다. 종료된 GATT나 이전 검색/연결의 늦은 콜백은 세대 번호로 무시한다.
- 기존 배속 안정화와 수동 일시정지 보존 정책을 그대로 적용한다. 연결이 끊기거나 유효 RPM이 없으면 자동 연동 중 영상을 일시정지한다. 사용자가 멈춘 영상은 센서가 임의로 재개하지 않는다.

## 권한·오류·개인정보
- Android 12 이상: BLUETOOTH_SCAN(neverForLocation), BLUETOOTH_CONNECT 런타임 권한. 카메라/마이크/위치 권한은 추가로 요구하지 않는다.
- Android 8~11: BLE 검색을 위해 레거시 Bluetooth 및 위치 권한을 Android 11까지로 제한한다. 실제 위치를 읽거나 저장하지 않으며 해당 Android 버전의 검색 요구사항을 안내한다.
- Bluetooth 꺼짐, 권한 거절, 검색 실패, 잘못된 모드, 서비스/알림 구독 실패, 연결 시간 초과, 연결 끊김을 별도 상태로 안내한다. Bluetooth 활성화는 사용자가 Android 시스템 화면에서 선택한다.
- 센서 식별자/마지막 선택만 네이티브 앱 내부에 저장한다. WebView에는 숫자 RPM과 상태·입력원만 전달한다. 센서 데이터와 주소를 외부 서버에 업로드하지 않는다.

## 검사와 전달
순수 Kotlin CSC 파서/차분 계산을 합성 바이너리 데이터로 검사한다: 60/90/120RPM, 바퀴+크랭크 필드, 필드 부족/잘못된 모드, 16비트 순환, 정지, 중복, 센서 초기화, 긴 수신 공백. 연결 상태/세대 차단과 JS 입력원 전환·배속·수동 정지·오래된 값·몰입 정보 회귀검사를 수행한다.

기존 패키지·서명키로 업데이트 APK를 만들고 GitHub roadride-app 브랜치로 소스/APK를 전달한다. Android 빌드·lint·서명과 자동검사를 수행한다. 실제 S314와 갤럭시탭은 개발 환경에 연결되어 있지 않으므로 실기기 검색/수신 성공이나 정확도 검증을 주장하지 않는다. 설치 후 사용자의 기기에서 센서 모드와 수신을 확인한다.
