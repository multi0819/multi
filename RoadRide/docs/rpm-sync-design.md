# RoadRide 1.1 — 주머니 RPM과 갤럭시탭 영상 연동

## 확정한 목적
휴대폰을 바지 앞주머니에 넣고 실내바이크를 타면 휴대폰 동작 센서로 추정한 RPM을 갤럭시탭에서 표시하고 영상 재생속도에 연결한다. 두 기기에 같은 안드로이드 APK를 설치하고 역할을 선택한다. 별도 센서, 카메라, 앱 구독 또는 외부 중계 서버는 사용하지 않는다.

## 사용자 흐름
1. 휴대폰에서 ‘RPM 측정기’를 선택하고 ‘측정 시작’을 누른다.
2. 휴대폰에 표시되는 연결 주소와 임시 연결 코드를 갤럭시탭의 ‘휴대폰 연결’에 입력한다. 두 기기는 같은 Wi-Fi를 사용한다. 마지막 주소는 기억하되 연결 코드는 측정 시작마다 새로 만든다.
3. 연결을 확인한 뒤 휴대폰을 바지 앞주머니에 넣는다. 화면을 끄거나 앱을 배경으로 보내도 명시적으로 시작한 측정은 알림이 표시되는 서비스에서 계속한다.
4. 갤럭시탭에서 코스를 선택하고 ‘RPM 자동 연동’을 켠다. 기본 기준 60RPM에서 영상 1배속이며 사용자가 기준을 조절할 수 있다.
5. 운동 후 휴대폰 앱 또는 알림의 ‘측정 종료’를 누른다. 자동 연동을 끄면 기존 수동 배속으로 사용할 수 있다.

## RPM 추정
50Hz 수준의 가속도 데이터를 짧은 이동 창에서 분석한다. 기기의 방향 변화에 대응하는 주기 분석과 진폭·신뢰도 검사를 사용한다. 실제 RPM을 정확히 측정했다고 표시하지 않으며 화면에 ‘추정 RPM’을 표시한다. 바지 주머니 위치·헐렁함·다리 움직임·진동이 결과에 영향을 줄 수 있다. 반회전/한회전의 반복 파형 혼동에 대비해 사용자가 0.5배·1배·2배 보정 계수를 고를 수 있게 한다. 정지와 재시작에는 몇 초의 인식 지연이 있을 수 있다. 30~150RPM 구간을 우선 검증한다.

## 영상 속도 연동
추정 RPM ÷ 사용자 기준 RPM으로 목표 영상 배속을 정하고 공식 YouTube 플레이어가 제공하는 배속 중 가까운 단계를 선택한다. YouTube 지원 배속 단계 때문에 무단계 속도 변화는 보장하지 않는다. 값을 완만하게 필터링하고 단계 변경에 히스테리시스를 적용해 작은 흔들림으로 배속이 계속 바뀌지 않게 한다. 페달 정지가 확인되면 일시정지하고, 유효 RPM이 돌아오면 자동 연동으로 멈춘 영상만 재개한다. 사용자가 직접 누른 일시정지를 RPM이 임의로 해제하지 않는다.

## 연결과 보안
휴대폰의 포그라운드 측정 서비스와 갤럭시탭의 네이티브 클라이언트가 로컬 Wi-Fi TCP 연결로 작은 RPM/신뢰도/상태 메시지만 교환한다. 임시 난수 코드로 연결을 인증하고 메시지 길이·값 범위를 제한한다. 인터넷으로 센서 데이터나 기기 주소를 업로드하지 않는다. 이 로컬 연결은 TLS가 아닌 방식이므로 신뢰하는 가정 Wi-Fi 사용을 안내한다. 공유기의 기기 간 통신 차단이 있으면 연결 실패를 안내한다. 태블릿 WebView가 HTTP 주소에 직접 접속하지 않도록 네이티브 코드에서 연결을 처리한다.

## 오류와 수명주기
연결 끊김, 오래된 측정값, 낮은 측정 신뢰도를 구분하여 표시한다. 자동 연동 중 연결이 끊기거나 값이 일정 시간 갱신되지 않으면 영상을 안전하게 일시정지한다. 측정기가 화면을 끄더라도 서비스가 센서를 수신하도록 구성한다. Android 권한 거절, 센서 없음, 배터리 제한 또는 시스템의 서비스 종료를 안내하고 수동 재생은 유지한다. 카메라·마이크·위치 권한은 요청하지 않는다. 화면 꺼짐 측정을 위해 필요한 포그라운드 서비스와 잠금 유지 권한만 추가한다. 원본 센서 데이터는 기기에 파일로 저장하지 않는다.

## 구현 범위와 검증
기존 APK를 업데이트 설치할 수 있도록 패키지와 서명키를 유지한다. 역할 선택·연결·측정 화면, 가속도 추정기, 측정 서비스, 로컬 통신, 태블릿 수신과 배속 연동을 추가한다. 실제 페달 동작의 회전수 정확도 및 기기 간 연결은 사용자의 휴대폰·갤럭시탭에서 확인해야 한다.

자동 검증은 알려진 회전수의 합성 센서 신호, 방향 변화·잡음·정지, 잘못된 연결 코드, 오래된 메시지, 지원 배속 선택, 수동 일시정지 보존, 재연결과 종료를 대상으로 한다. APK 빌드·서명·Android lint와 기존 회귀검사를 수행한다. 실제 센서 정확도와 화면 꺼짐 동작을 실기기에서 검증하지 못하면 전달 시 명시한다. 결과물은 GitHub 소스, APK, 한국어 연결 안내다.
