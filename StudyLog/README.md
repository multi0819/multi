# 학습기록 Android 1.0.0

기존 multi0819/multi 웹앱 화면을 유지한 오프라인 Android 앱입니다. 기록과 사진은 앱 전용 WebView IndexedDB에 저장됩니다. 서버 연결이나 인터넷 권한이 없습니다. 데이터베이스를 별도 Room DB로 재작성한 앱은 아닙니다.

## 기존 기록 이동
1. 기존 웹앱에서 메뉴 → 백업 → JSON 백업을 저장합니다. 이 파일에는 기록과 사진이 포함됩니다.
2. APK를 설치하고 메뉴 → 백업 → 백업 불러오기에서 JSON 파일을 선택합니다.
3. 기록과 사진을 확인한 뒤 웹앱을 정리하세요. 복원은 현재 APK의 기록을 대체하므로 사용 중인 APK에서도 먼저 JSON 백업을 만드세요.

## 사용
- JSON / CSV / TXT 저장은 Android 파일 저장 창에서 원하는 위치를 선택합니다.
- PDF 저장은 Android 인쇄 창에서 PDF로 저장을 선택합니다.
- 읽어주기는 휴대폰의 한국어 TTS 엔진을 사용합니다. 오프라인 음성 재생에는 한국어 음성 데이터가 설치되어 있어야 합니다.
- 앱 삭제 / 앱 데이터 삭제 시 기록이 삭제됩니다. 주기적으로 JSON 백업을 별도 보관하세요.
- 웹앱의 브라우저 자동 다운로드 방식 주간 백업은 APK에서 사용하지 않습니다. 수동 JSON 백업을 이용하세요.
- 인터넷의 외부 이미지 주소를 본문에 직접 넣은 경우 오프라인에서 표시되지 않습니다. 사진 첨부 기능으로 저장된 사진을 사용하세요.

## 빌드
Java 17, Android SDK 35, Gradle 8.11.1에서 서명 키 복원 후 빌드합니다.

```sh
base64 --decode signing/studylog.jks.b64 > signing/studylog.jks
gradle assembleRelease
```
signing/studylog.jks는 개인용 테스트 배포에 사용하는 공개 개발 키입니다. 업데이트 시 같은 키를 유지해야 합니다. Play Store 공개 배포에는 별도의 비공개 서명 키가 필요합니다.

## 검증 범위
APK 컴파일·패키징·서명, JS 음성 콜백·취소, 백업 바이트 전달, 기록 저장·재시작·이미지 포함 복원을 검사합니다. 실제 삼성 기기에서 파일 선택기·음성·인쇄 동작은 설치 후 확인해야 합니다.
