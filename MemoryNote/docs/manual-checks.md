# 수동 검증 절차

아래는 기기에서 수행할 절차이며, 체크되지 않은 항목은 아직 실기기 검증하지 않았습니다.

- [ ] 공조냉동 과목과 기본 단원 확인. 다른 과목과 단원 추가 및 이름 변경.
- [ ] 긴 한글·특수문자·줄바꿈 노트를 저장하고 앱을 종료 후 재실행해 비교.
- [ ] 문구를 선택해 빈칸 지정. 복습에서 숨김·공개 확인.
- [ ] 문답·오답노트의 문제·내 답·정답·틀린 이유·주의점 저장 및 재조회.
- [ ] 사진 여러 장 선택, 선택 취소, 지원하지 않는 형식, 저장 공간 부족 처리.
- [ ] 사진 가림 사각형 추가·제거, 확대, 복습 중 숨김·공개 확인.
- [ ] 저장하지 않은 초안을 다른 앱 이용 후 이어쓰기. 화면 회전과 강제 종료 후 복구.
- [ ] 제목·내용·태그 검색, 과목·단원·유형·이해도·즐겨찾기 필터.
- [ ] 모름·헷갈림·외웠음 평가 후 예정일과 복습 횟수 확인.
- [ ] 사진과 가림을 포함해 백업한 뒤 새 노트를 만들고 백업 복원. 내용과 이미지 비교.
- [ ] 손상 ZIP·사진 누락·중복 경로·미지원 버전 거부 후 기존 데이터 유지 확인.
- [ ] 기본/큰/아주 큰 글씨, 다크모드, 작은 화면과 폴더블 화면 확인.
