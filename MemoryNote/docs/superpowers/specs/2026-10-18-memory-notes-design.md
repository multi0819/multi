# 암기노트 앱 설계안

## 목표
공조냉동 시험 공부에 먼저 사용하고 다른 과목도 자유롭게 추가한다. 글이 주 입력 수단이며 사진도 첨부한다. 개인용 안드로이드 설치 앱을 기준으로 한다.

## 화면과 기능
- 홈: 오늘 복습할 노트 수, 최근 노트, 빠른 작성 버튼.
- 과목: 과목과 단원을 추가·수정하고 해당 노트를 모아 본다. 기본 과목은 공조냉동이며 단원은 자유롭게 변경한다.
- 노트: 제목, 본문, 과목, 단원, 태그, 사진 여러 장, 즐겨찾기를 저장한다. 일반 노트·문답 카드·오답노트 유형을 제공한다.
- 문답 카드: 질문과 정답을 따로 작성하고 복습 중 정답을 가린다.
- 빈칸 암기: 본문에서 선택한 문구를 빈칸으로 지정한다. 복습 시 가리고 눌러 확인한다.
- 사진: 갤러리에서 추가하고 확대·삭제한다. 사진 일부를 사각형으로 가리고 복습 시 공개한다. 원본 사진을 변경하지 않는다.
- 오답노트: 문제, 내 답, 정답·해설, 틀린 이유, 다음에 확인할 내용을 작성한다. 사진 첨부와 일반 노트의 오답 전환을 지원한다.
- 복습: 정답 확인 후 모름·헷갈림·외웠음 중 선택한다. 모름은 다음 날, 헷갈림은 3일 뒤, 외웠음은 연속 성공 횟수에 따라 7·14·30일 뒤로 예약한다. 모름을 선택하면 연속 성공 횟수는 초기화한다. 아직 평가하지 않은 노트도 복습 대상이다. 오늘 예정된 노트와 기한이 지난 노트를 모름·헷갈림 우선으로 보여준다. 별도로 언제든 전체·과목별 복습이 가능하다.
- 검색: 제목·본문·질문·정답·오답 이유·태그를 검색하고 과목·단원·유형·이해도·즐겨찾기로 필터링한다.
- 통계: 과목별 노트 수, 이해도 분포, 날짜별 복습 수를 보여준다.
- 설정: 글자 크기, 밝은 테마·어두운 테마, 백업·복원.

## 저장과 백업
로그인 없이 오프라인으로 사용한다. 노트와 첨부 사진을 앱 전용 저장소에 보관한다. 백업은 사진·가림 영역·노트·복습 이력을 모두 포함하는 버전 명시 ZIP 파일이다. 사용자가 저장 위치를 선택한다. 복원 전 파일 구조와 필수 항목을 검증하고 기존 데이터를 대체할지 확인한다. 오류가 있으면 기존 데이터를 유지한다. 앱 삭제 전에 별도 백업이 필요함을 설정 화면에 안내한다.

## 데이터 구조
과목, 단원, 노트, 사진 첨부, 텍스트 빈칸, 사진 가림 영역, 복습 이력으로 구성한다. 각 항목은 고유 ID를 갖는다. 사진 가림 영역은 이미지 크기에 대한 상대 좌표로 저장한다. 날짜별 복습은 휴대폰 현지 날짜를 기준으로 계산한다.

## 구현 방향
안드로이드 네이티브 앱과 로컬 데이터베이스를 우선한다. 제작 환경에서 APK 생성 경로를 먼저 확인한다. 자동 AI 문제 생성과 온라인 동기화는 이번 범위에 포함하지 않는다. 사진 첨부와 가리기는 수동으로 조작한다.

## 검증 기준
글·사진 노트의 생성·수정·삭제 후 앱을 다시 열어도 유지되는지 확인한다. 빈칸·사진 가림과 문답의 정답 공개를 확인한다. 오답 항목 저장, 검색·필터, 복습 날짜 계산, 날짜 변경을 검증한다. 사진을 포함한 백업을 새 데이터 상태에 복원해 항목과 이미지가 일치하는지 확인한다. 손상된 백업의 복원을 거부하고 기존 데이터를 보존하는지 확인한다. 작은 화면·큰 글씨·뒤로가기·한글 입력을 확인한다. APK 생성과 실제 기기 동작 검증은 구분해 보고한다.
