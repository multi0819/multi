# 암기노트 1.4.0

안드로이드 오프라인 암기노트. 기존 1.1.0의 색 구분과 복수 문구 가림을 유지합니다.

## 읽어주기
홈에서 전체 문제, 과목 화면에서 해당 과목, 상세 화면에서 단일 문제 읽기를 시작합니다.
첨부 이미지가 하나라도 있는 노트는 자동 제외합니다. 문제를 읽고 3초 후 정답을 읽으며 다음 문제로 넘어갑니다.
읽기 정지, 다시 시작, 다음 문제, 종료를 지원합니다. 앱이 배경으로 가거나 화면이 꺼져도 재생을 이어갑니다.
가림/색상용 표시는 발음하지 않습니다. 한국어 TTS 엔진이 필요하며, 없는 경우 설정 안내를 표시합니다.
복습 평가나 저장된 노트 데이터는 바꾸지 않습니다.

## 빌드
Java 17, Android SDK platform 35, build-tools 35.0.0. local.properties에서 sdk.dir을 지정하고 ./gradlew testDebugUnitTest assembleDebug를 실행합니다.
업데이트 배포 시 기존 MemoryNote-update-key.jks로 APK에 서명해야 합니다. 서명 키는 소스 묶음에 포함하지 않습니다.

## 검증
기존 JUnit 30개 통과, 핵심/백업/표시/선택/읽기 독립 검증 44개 통과.
APK 컴파일, DEX 생성, v2/v3 서명 검증, 기존 1.1.0과 서명 및 패키지 일치 확인.
실제 기기 설치/음성 출력은 이 환경에서 검증하지 않았습니다.

## 1.2.1 설치 오류 수정
수동 APK 포장 시 resources.arsc가 압축되는 오류를 수정했습니다. scripts/package_apk.py는 aapt2가 생성한 각 ZIP 항목의 압축 방식을 보존합니다. 포장 후 zipalign, 서명, tests/check_apk.py 순서로 검사해야 합니다. 1.2.0 APK는 압축 검사에 실패하고 1.2.1은 비압축·4바이트 정렬·체크섬 검사에 통과합니다. 실제 기기 설치는 검증하지 못했습니다.

## 1.3.0 변경 사항
- 과목·단원·유형을 먼저 선택합니다. 일반 노트는 그 아래에 제목과 내용만 표시하며 기존 가리기 기능을 유지합니다.
- 문답은 문제·답만 입력합니다. 목록 제목은 문제에서 자동 생성되며, 복습에서는 답 전체를 가립니다.
- 오답노트에서만 내 답·틀린 이유·주의사항을 추가로 표시합니다.
- 사진·태그·즐겨찾기는 접을 수 있는 공통 옵션에 모았습니다.
- 답 지정은 파랑, 가리기는 주황, 저장은 초록으로 구분하고 버튼 배경·테두리와 선택 메뉴의 대비를 개선했습니다.
- 기존 노트·읽어주기와 사진 문제 제외 기능을 유지합니다. 유형 전환 시 빈 입력란에만 기존 내용을 옮기며 원래 내용은 보존합니다.
- 작성 화면과 노트 목록은 세로 스크롤을 지원합니다.

### 작성 화면 실행 검사
테스트 APK를 설치한 뒤 `adb shell am instrument -w kr.memorynotes.test/kr.memorynotes.EditorSmokeRunner`로 일반·문답 분리, 색 대비, 120개 목록과 긴 내용 스크롤을 확인할 수 있습니다. 이 검사는 테스트용 에뮬레이터에서 실행하세요.

## 1.3.1 읽어주기 업데이트
- 홈 화면으로 이동하거나 화면을 꺼도 문제 → 생각할 시간 → 정답 재생을 이어갑니다.
- 알림과 잠금 화면의 미디어 제어에서 정지·계속 읽기·종료할 수 있습니다.
- 앱의 읽어주기 창에서 ‘읽기 종료’를 누르면 재생을 끝냅니다. 다른 오디오에 재생 권한을 넘기면 정지하며, 다시 읽기 시작을 눌러 이어갈 수 있습니다.

## 1.4.0 목록·복습 범위 업데이트
- 홈에 정리한 노트를 개수 제한 없이 표시합니다. 상단 안내와 조작부는 고정되며 노트 목록만 스크롤됩니다.
- 전체 노트 수와 오늘 복습할 노트 수를 따로 표시합니다. 복습 예정일이 미래인 노트는 전체에는 포함되지만 오늘 복습에서는 제외됩니다.
- 전체 복습에서 과목·단원·유형·이해도·즐겨찾기 및 전체/오늘 범위를 조합하고 대상 건수를 확인할 수 있습니다.
- 검색에서 모든 과목의 단원을 선택할 수 있고, 과목을 바꾸면 단원 목록과 선택을 갱신합니다. ‘단원 없음’도 지원합니다.
- 검색한 조건의 노트만 복습하거나 읽어줄 수 있습니다.

## 1.5.0 S펜 필기 · 선택 글자색
- 작성·상세·복습 화면에서 S펜으로 필기하고 손가락으로 스크롤합니다. 펜을 끄면 S펜으로도 텍스트를 선택/입력할 수 있습니다.
- 펜/지우개, 색·굵기, 되돌리기, 확인 후 전체 지우기를 제공합니다. 버튼과 선택 컨트롤은 필기 대상에서 제외합니다.
- 필기는 노트의 텍스트/이미지 영역에 연결하여 저장하고, 기존 JSON 백업에도 포함합니다. 본문 편집으로 내용의 줄바꿈·구조를 바꾸면 필기와 글자의 상대 위치는 달라질 수 있습니다.
- 입력란에서 글자를 길게 눌러 선택한 뒤 ‘글자색’을 누르면 5가지 색 또는 기본색을 적용합니다. 글자색은 저장·다시 열기·복습에서 유지합니다.
- 호환성·색 범위·필기 기하·기존 기능 JUnit 53개, 독립 검증 58개 통과. 실제 태블릿/S펜 입력은 이 환경에서 검증하지 못했습니다.
