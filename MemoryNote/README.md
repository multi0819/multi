# 암기노트 · MemoryNote

공조냉동부터 여러 과목까지, 오프라인으로 쓰는 안드로이드 암기·오답노트 앱입니다.

## 기능
- 과목·단원 추가 및 이름 변경
- 글과 여러 장의 사진을 함께 저장, 검색, 즐겨찾기
- 일반 노트, 문답 카드, 오답노트
- `{{외울 문구}}` 빈칸 암기와 사진 사각형 가리기
- 모름·헷갈림·외웠음에 따른 1·3·7/14/30일 복습
- 전체·과목별 복습과 오늘 복습, 날짜별 학습 횟수
- 사진까지 포함하는 ZIP 백업·복원
- 글자 크기와 다크모드, 임시 작성 내용 보존

인터넷·계정·외부 저장소 전체 접근 권한을 요구하지 않습니다. 사진과 백업은 시스템 파일 선택기를 이용합니다. 사진은 한 장당 25MB, 복원 ZIP은 압축 해제 후 512MB까지 지원합니다.

## 사용
과목을 선택하거나 홈에서 새 노트를 작성합니다. 내용을 길게 눌러 선택한 후 ‘빈칸으로 지정’을 누르세요. 사진의 ‘가림 설정’에서 드래그해 가릴 영역을 만듭니다. 복습 중 정답을 확인하고 이해도를 선택하면 다음 날짜가 예약됩니다.

앱 삭제 전에 설정에서 백업을 저장하세요. 복원하면 현재 노트와 복습 이력이 백업 내용으로 대체됩니다. AI 해설·OCR·온라인 동기화는 포함하지 않습니다.

## 빌드
JDK 17과 Android SDK 35가 필요합니다.

```sh
./gradlew testDebugUnitTest assembleDebug
```

생성 파일: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions는 전용 브랜치의 변경 또는 수동 실행으로 테스트와 APK artifact를 생성합니다. 제공되는 첫 설치본은 테스트 서명입니다. 이후 업데이트 시 같은 서명 키를 사용해야 하며, 키를 바꾸면 기존 앱 위에 설치할 수 없습니다. 키는 저장소에 포함하지 않습니다.

## 검증
JVM 테스트는 복습 날짜·한글 왕복·사진 누락·잘못된 가림 좌표·중복 노트·단원 연결·백업 경로·버전 검증을 검사합니다. 실제 기기에서 별도로 확인할 절차는 `docs/manual-checks.md`에 기록합니다.

## 1.1.0 변경 사항
제목·문제는 기본색, 답은 파랑, 가림 문구는 주황으로 구분합니다. 작성 화면에서 답 부분을 블록 선택 후 ‘답 지정’을 누르면 그 안의 개별 가림 문구는 주황으로 유지됩니다. ‘가림 문구 여러 개 설정’에서 원하는 문구를 반복 추가하거나 여러 줄을 체크한 뒤 한 번에 적용하세요. 복습 중 각 주황색 빈칸을 누르면 해당 문구만 확인할 수 있습니다.

기존 노트 구조와 복습 기록을 유지하며, 버전 코드 2 / 버전 1.1.0입니다. 설치 APK는 `downloads/MemoryNote-1.1.0.apk`에 있습니다.
