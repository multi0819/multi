# MemoryNote 2.0.0 — PDF study and capture

User-authorized integrated PDF study. Entry at the top of note creation: PDF 불러오기 · 공부 이어서. Document-first screen contains compact move/select/pen/eraser/color/width tools, page navigation, focus mode, and 암기 추가. A selected rectangle is previewed before saving. 문제 always creates a fresh general Note; 지문/풀이 append to the displayed current note, including captures from other pages. Title is confirmed as text; PDF captures themselves remain images, preserving diagrams/formulas without OCR. Solution images receive existing full-image masks, so the normal general-note reveal flow hides them before reveal.

Current-note menu supports view/edit, choosing another existing PDF-created note, undoing the most recent addition, moving its role, and returning to its source document/page. Original PDF link is added to captured note detail. Page, zoom/pan, document list, current note and source clip records are stored atomically. Page ink is normalized, supports pen/eraser/undo/clear, is included in crops, and is stored per-page with AtomicFile. Unreadable ink becomes read-only instead of being overwritten; unreadable document metadata blocks writes. Backup-only AtomicFile metadata is recovered.

Large PDFs are streamed to a private file, not loaded as a byte array. Only current page is rendered (max width2048 and max3M pixels) on a serial worker, with stale-request bitmap cleanup. Zoom is relative to fitted page; selection has adjustable corners. Activity result9042, back/pause/destroy hooks preserve old handlers and release page/worker resources.

Persistence uses the existing Note schema and UUID .img markers; new document/clip records are under private pdfstudy/state.json. Existing note backups include captured images but DO NOT include PDF originals or PDF-page handwriting/source metadata. Users must retain original PDFs; exporting full PDF study state is not implemented. No OCR, text extraction or AI service is simulated. Password-protected/malformed PDFs may fail native rendering. 400MB files and device performance were not tested.

Build from verified1.9.3 APK, Java17/javac, Android23 jar, R8 8.3.37, apktool2.11.1 and existing update keystore (external). Same build.py arguments/environment as earlier updates. App ID kr.memorynotes unchanged; version2.0.0/code40. Compile-only app/framework stubs are excluded; package only Pdf* and StudyPdfCanvas* classes. Generated smali/snapshots are reproducible and gitignored. Native resources remain byte-preserved.
