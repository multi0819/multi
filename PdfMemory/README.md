# PDF 암기노트

별도 Android 앱 (`kr.pdfmemorynotes`), 버전 1.0.0. 기존 `kr.memorynotes` 앱의 파일, 설치 식별자, 데이터베이스와 독립입니다.

## 사용
1. ‘PDF 불러와 자동 카드 만들기’에서 파일을 한 번 선택합니다.
2. 앱 안의 한국어 OCR 모델이 페이지를 차례로 인식합니다. 화면을 떠나도 foreground service로 처리하고 완료된 페이지를 저장합니다.
3. ‘오늘 복습’은 확인을 마친 카드 중 복습일이 지난 카드만 보여 줍니다. ‘전체 복습’과 ‘확인 필요’는 별도입니다.
4. 의심스러운 카드만 원본을 확인하고 ‘이대로 사용’을 누르거나 수정합니다. 수식·그림은 원본 PDF 영역도 함께 제공합니다.

## 자동화 범위와 한계
현재 자동 분리 규칙은 제공된 교재 표본처럼 파란 문제 번호와 청색 해설 구분선/표시가 있는 형식을 대상으로 보수적으로 작성했습니다. 번호가 흐리거나 없는 페이지, 다른 배치, 해답 누락, 별도 해답책의 번호 매칭은 확인이 필요하며 정확한 자동 연결을 보장하지 않습니다. 일반 PDF를 지원한다는 이유로 모든 교재의 자동 분리가 검증된 것은 아닙니다.

PDF는 버퍼를 이용해 앱 전용 저장소에 한 번 복사하고 SHA-256으로 중복을 확인합니다. 분석용 비트맵은 최대 4백만 픽셀, 긴 변 2600px로 제한합니다. OCR 기록과 카드 분리는 한 페이지씩 읽으며 카드당 텍스트도 제한합니다. 원본 PDF는 보존합니다. 입력 PDF 파일 크기만으로 메모리 사용을 보장할 수는 없습니다.

앱은 인터넷 권한을 요청하지 않습니다. 한국어 인식 모델을 앱에 포함합니다. 사용자 제공 PDF나 추출한 교재 내용은 이 저장소에 포함하지 않습니다.

## 검증
- Gradle 단위 테스트: 구분/계속 페이지/하위 번호/번호 누락/중복/빈 페이지/렌더 한도/페이지 스트리밍/색상 마커 검사.
- 제공된 19페이지 스캔 PDF를 데스크톱 OCR + 동일 Java 마커/분리 코드로 시험해 14개 후보를 식별했습니다. 데스크톱 엔진은 Tesseract이며 Android ML Kit와 다른 엔진입니다. Android에서 같은 인식 정확도가 나온다고 검증한 것은 아닙니다.
- Android 35 release 빌드, lint, APK 패키지/서명 검증.
- 실제 삼성패드 설치·입력·ML Kit 실행과 원본 400MB 파일은 미검증입니다.

## 빌드
JDK 17, Android SDK 35/build-tools 35.0.0, Gradle 8.9.

`./gradlew testDebugUnitTest assembleRelease lintDebug`

release APK는 별도 보관하는 업데이트 키로 서명합니다. 저장소에는 키나 비밀번호가 없습니다.
