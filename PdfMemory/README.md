# PDF 암기노트 1.1.0

별도 앱 ID `kr.pdfmemorynotes`. 기존 MemoryNote의 데이터와 분리됩니다.

PDF를 선택하면 문서 보기로 열립니다. 자동 OCR이나 문제·정답 자동 분리는 실행하지 않습니다. 페이지를 넘기거나 번호를 눌러 이동하고, 확대해서 필요한 부분을 확인할 수 있습니다.

삼성 AI 셀렉트는 사용자가 시스템 기능으로 실행합니다. 텍스트를 복사한 뒤 하단 ‘문제 붙여넣기’ 또는 ‘정답 붙여넣기’를 누릅니다. 이미지 URI가 클립보드로 제공되면 사진도 담을 수 있습니다. 기기에서 이미지 복사를 제공하지 않는 경우, AI 셀렉트에서 저장한 사진을 ‘편집·저장’의 사진 첨부로 선택합니다. 앱이 삼성 AI 셀렉트를 직접 호출하거나 자동으로 선택하는 기능은 아닙니다.

작성 내용은 문서별로 임시 저장됩니다. 페이지를 넘겨 문제와 정답을 따로 담은 후 ‘편집·저장 → 카드 저장’을 누르면 같은 PDF 페이지에 머무릅니다. 글과 사진을 섞을 수 있으며 사진은 각 면에 6장까지, 한 장당 32MB까지입니다. 단어를 선택해 가릴 수도 있습니다. 복습에서는 정답 확인 후 가린 문구를 확인합니다.

기존 PDF와 카드·필기·복습 일정은 유지합니다. DB v2는 기존 카드에 문제·정답 사진 필드만 추가합니다. 이전 자동 카드 생성 코드는 더 이상 실행하지 않으며 기존 자동 카드 원본은 계속 볼 수 있습니다.

PDF는 스트리밍 복사해 보관하고 문서 보기에서는 한 페이지씩 렌더링합니다. 400MB 원본과 실제 삼성 AI 셀렉트의 클립보드 동작은 실기기 검증이 필요합니다. 사용자 PDF나 추출한 교재 내용은 저장소에 포함하지 않습니다.

## 빌드
JDK 17, Android SDK 35/build-tools 35.0.0, Gradle 8.9.

`./gradlew testDebugUnitTest assembleRelease lintDebug`

release APK는 별도로 보관한 기존 업데이트 키로 서명합니다.
