# PDF 암기노트 Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 기존 앱을 유지하며 별도 이름·패키지의 PDF 학습 앱을 제작한다.

**Architecture:** Android PdfRenderer로 페이지를 한 장씩 처리한다. 선택 영역의 OCR 결과와 원본 이미지 참조로 문답카드를 저장하며 데이터는 별도 앱 전용 디렉터리에 둔다.

**Tech Stack:** Java, Android native Views/PdfRenderer, 한국어 OCR, Android 앱 전용 저장소.

**Spec:** ../specs/2026-10-23-pdf-memory-design.md

## Global Constraints
- 이름 PDF 암기노트, 식별자 kr.pdfmemorynotes.
- 기존 kr.memorynotes 앱·데이터·업데이트 APK를 변경하지 않는다.
- 400MB 전체를 메모리로 읽지 않는다. 원본 파일이 없어 해당 파일 검증은 미완료다.

## Review Focus
- 대용량/저장 공간 부족: 임시 파일을 정리하고 기존 PDF를 보존한다.
- 손상/암호화 PDF: 앱 종료 대신 오류를 안내한다.
- 페이지 이동 중 연속 입력/회전: 이전 작업이 최신 페이지를 덮지 않게 한다.
- OCR 실패/모델 다운로드 실패: 원본 이미지를 보존하고 수동 입력을 제공한다.
- 저장 실패/프로세스 종료: 저장된 카드·원본·마지막 위치를 복원한다.

### Task 1: 별도 앱과 페이지 뷰어
- [ ] PdfMemory 폴더에 별도 Gradle 앱과 manifest를 만든다.
- [ ] 파일 선택/현재 페이지 렌더링/페이지 이동/마지막 위치를 구현한다.
- [ ] 대용량 메모리 한도, 취소, 잘못된 파일, 저장 부족 검사를 추가한다.

### Task 2: 자동 문제·정답 추출과 OCR
- [ ] 제공된 PDF의 텍스트 유무, 단·문제 번호·단원·정답/해설 배치를 조사하고 자동 분리 기준을 확정한다.
- [ ] 실제 배치를 본뜬 다단·번호 반복·페이지 넘김·별도 해설·누락/중복 정답 테스트를 작성한다.
- [ ] 번호와 단원 기반 문제/정답 연결, 확실한 카드 자동 등록과 불확실 항목만 확인하는 흐름을 구현한다.
- [ ] 페이지별 체크포인트와 재실행 중복 방지 검사를 추가한다.
- [ ] 실패 항목을 위한 영역 수정 좌표 정규화·잘라내기 테스트를 작성한다.
- [ ] 선택 영역 한국어 OCR, 편집 가능한 결과와 원본 이미지 보존을 구현한다.
- [ ] OCR 실패·작업 취소·페이지 변경 경합을 검사한다.

### Task 3: 카드 저장·복습과 배포
- [ ] 카드 저장/복원과 단계별 공개 흐름 테스트를 작성한다.
- [ ] 별도 앱 저장소에 카드와 PDF 참조를 보관한다.
- [ ] 원래 앱과 다른 패키지, 기존 앱의 무변경, APK 서명·빌드를 검사한다.
- [ ] 새 파일로 배포하며 검증 범위와 미확인 사항을 구분한다.
