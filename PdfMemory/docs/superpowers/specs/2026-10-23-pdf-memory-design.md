# PDF 암기노트 — 별도 앱 설계

기존 MemoryNote 앱과 데이터를 변경하지 않고, PDF 학습 기능을 별도의 안드로이드 앱으로 만든다.

- 표시 이름: PDF 암기노트
- 앱 식별자: kr.pdfmemorynotes (기존 kr.memorynotes와 분리)
- 파일·설정·노트·업데이트 경로를 기존 앱과 분리한다. 두 앱을 동시에 설치한다.
- PDF를 선택해서 열고 마지막 페이지를 기억한다. 400MB 파일 전체를 메모리로 읽지 않고 현재 페이지 중심으로 렌더링한다.
- 사용자가 PDF를 한 번 선택하면 문제 번호·정답/해설 제목·페이지 배치를 분석하여 문답카드 후보를 자동 생성한다. 페이지별 영역 지정과 복사·붙여넣기는 기본 흐름에서 요구하지 않는다.
- 문제와 해설이 떨어진 페이지에 있으면 문제 번호와 단원으로 연결한다. 같은 번호가 단원마다 반복되면 단원 경계를 포함해 대응한다.
- 확실한 후보는 자동 저장하고, 정답 누락·번호 충돌·다단 읽기 순서 오류 가능성이 있는 후보만 ‘확인 필요’에 모은다. 연결이 불확실하면 정답을 추측해서 채우지 않는다.
- 자동 분석이 실패한 페이지에 한해 영역 수정 기능을 제공한다. 한 번 수정한 배치는 유사한 다음 페이지에 재사용할 수 있게 한다.
- 변환은 진행 위치를 저장하며 중단·재실행 후 이어서 처리한다. 같은 PDF의 완료된 카드가 중복 생성되지 않게 한다.
- 전체 분석 전 앞부분 일부를 분석하여 번호·단원·해설 연결 규칙이 맞는지 검사한다. 원본 PDF가 아직 없으므로 이 문서의 자동 분리 규칙은 구현 전 가정이며 정확도를 보장하지 않는다.
- 선택 영역의 한국어 글자를 OCR로 추출하여 문제·정답 입력란에 넣는다. OCR 결과를 확인·수정하고 저장한다. 수식·표·그림은 원본 영역 이미지도 보관한다.
- 복습은 문제 → 정답 확인 → 가린 문구 확인 → 다시 가리기 순서. 영역 이미지와 텍스트를 함께 볼 수 있다.
- 오류·취소·저장 공간 부족·암호화된 PDF를 안내하고 기존 학습 자료를 유지한다.

## 접근 방식

기존 앱에 PDF 기능을 추가하면 기존 학습 흐름에도 영향을 줄 수 있다. 별도 앱으로 설치하면 사용자가 안정적인 기존 앱으로 계속 공부하면서 새 PDF 기능을 따로 확인할 수 있다. 사용자의 별도 이름 요청에 따라 별도 앱 방식을 채택한다.

## 검증 범위

원본 400MB PDF가 현재 제공되지 않았다. 작은/다중 페이지/손상 PDF, 인식 오류, 취소, 저장 복원, 메모리 한도와 APK 서명·패키지 분리는 자동 검사한다. 실제 파일과 삼성패드에서 확인하지 못한 성능·동작은 미검증으로 명확히 안내한다. 오류가 없다는 보장은 하지 않는다.

사용자는 별도 앱 구성에 대해 ‘최대한 손이 덜 가게’ 자동화를 요구했다. 실제 PDF 파일을 받아 페이지 구조와 문제·정답 배치를 확인하는 것이 자동 분리 규칙을 확정하기 위한 남은 입력이다. 기존 앱은 계속 사용 가능해야 한다.
